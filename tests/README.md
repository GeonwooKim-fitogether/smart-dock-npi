# 실기 시험 계획

결과는 해당 안건 이슈에 댓글로 남기고, 측정 데이터는 이 폴더에 `YYYY-MM-DD_시험이름.md` 로 저장한다.

| No | 시험 | 무엇을 가리나 | 관련 안건 | 상태 |
|---|---|---|---|---|
| T1 | 핫스팟 켠 뒤 Dock(또는 SBC)이 자동으로 붙기까지 시간 — iPhone · Android | 코치 대기 시간, 자동 재접속 동작 | 업로드 경로 · 결과 알림 | 계획 |
| T2 | 핫스팟 망에서 폰으로 `smartdock.local` Dock 화면이 열리는가 (⑧) | 업로드 중 폰 조작 가능 여부 | 업로드 경로 · 결과 알림 | 계획 |
| T3 | A안: 모듈이 핫스팟에 붙어 있는 동안 셀 쪽 Dock Wi-Fi 가 유지되는가 | 라디오 1개 겸용의 한계 | 업로드 경로 | 계획 |
| T4 | 케이스를 닫은 상태의 업로드 속도 (셀룰러 속도와 함께 기록) | Wi-Fi 구간이 병목이 되는가 | 업로드 경로 | 계획 |
| T5 | 셀 1대당 세션 파일 크기 (M2) | 업로드 시간 · 데이터 사용량 (현재 하루 약 3 GB 추정) | 결과 알림 · 사용자 플로우 | 계획 |

판단 기준(제안): 케이스 안 Dock 쪽 Wi-Fi 속도가 셀룰러의 1.5배 이상이면 A·B안 성능은 같다고 보고 구조가 단순한 쪽을 고른다.
