DataManager 화면을 그대로 옮긴 Smart Dock 웹 화면

기존 고객이 PC에서 쓰던 DataManager의 메뉴와 화면 짜임을 그대로 가져왔습니다. 다른 점은 PC 프로그램이 아니라, Dock Wi-Fi에 붙은 휴대폰이나 노트북의 브라우저에서 열린다는 것입니다. 가짜 데이터이고 추출 시간은 10배 빠르게 흐릅니다.

DataManager에서 그대로 가져온 것

  • 메뉴 넷의 이름과 순서: Upload, HR ID, SSID, Update
  • 메뉴마다 다른 강조색 (Upload 청록, HR ID 분홍, Update 보라)
  • 위쪽 단계 카드: 지금 할 카드만 채워 보이고, 다음 카드는 선만, Overall은 검정
  • 아래 칸 선반과 빈 칸의 "No cell"
  • 머리줄의 팀 선택

Smart Dock에서 바뀐 것

  • 셀을 Cell X 실물 외곽선으로 그림
  • 36칸 대신 24칸 (DKPX-2)
  • Upload에서 START 한 번이면 추출과 업로드가 이어짐
  • 칸마다 실패 표시와 다시 받기
  • Overall에 경과 시간과 목표(10분), LiveHub(5분)
  • 머리줄에 전원과 인터넷 상태, Dock 메뉴 신설
  • 휴대폰에서는 메뉴가 아래로 내려감

해 볼 것

  1. Upload에서 START를 누른다
  2. 7번 칸이 빨개지면 RETRY FAILED로 다시 받는다
  3. 아래 조작에서 인터넷을 켜고 업로드를 본다
  4. Update 메뉴에서 전원을 배터리로 바꿔 본다

시안 조작 — 실제 화면에는 없음

이 화면이 지키는 규칙

  • S1추출 시간을 목표 10분과 LiveHub 5분에 대어 보인다
  • S5실패한 칸은 바로 표시하고 다음 할 일을 알린다
  • E9인터넷이 없으면 Dock에 보관했다가 올린다
  • E10셀 원본은 서버 도착 확인 뒤에만 지운다
  • E11추출 뒤 한동안 조용하면 스스로 꺼진다
  • E12펌웨어 변경은 어댑터를 꽂았을 때만
