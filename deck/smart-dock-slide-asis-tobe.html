6.스마트폰 사용자 플로우 (개선 B · 코치 기준)

접속 정보는 최초 1회만 등록하고, 매 경기 코치 조작은 화면 열기 · START · 핫스팟 켜기 · 끄기 4회로 한정함

최초 1회(설치일 · 폰 교체 · 핫스팟 비밀번호 변경 시)

매 경기(5-A · 5-B쪽 ①~⑥ · 조작 4회 · 대기 2회 · 두 안 동일)

보는 곳Dock 웹 = SBC가 만든 페이지를 폰 브라우저가 표시 (같은 망 + 주소 · 앱 없음) · 폰 기본 설정 = 폰이 직접 표시 · Dock 표시등 = 본체 불빛

어긋나면④에서 '연결된 기기 0' 유지 (폰 이름·핫스팟 비밀번호 변경, 폰 교체) → 핫스팟 끄고 Dock Wi-Fi 재접속 → 다. 재등록

요구 · 주의결과 알림 방식 (7쪽 · 팀 논의) · 핫스팟 켠 뒤 설정 화면 유지 (Apple 권고) · 셀룰러 약 3 GB/일 (실측 전)

10.배터리 선정 검토

맞춤 배터리 팩은 MOQ로 제외하고, 1셀 상용 원통형(18650)을 기본안으로 셀 배터리 공용안과 비교하여 사용 환경(1·2안) 결정 시 확정함

필요 조건
